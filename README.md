## Deploying to Cloudflare Pages

1. Create a GitHub repository.

2. Upload all files.

3. Login to Cloudflare.

4. Pages

5. Create Project

6. Connect GitHub

7. Select this repository

Framework preset:

```
None
```

Build command:

```
(empty)
```

Output directory:

```
/
```

Deploy.

Then connect

```
www.fellfield.xyz
```

under

```
Custom Domains
```

Cloudflare automatically provisions SSL.
